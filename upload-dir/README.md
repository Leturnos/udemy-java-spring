# Upload Directory (`upload-dir`)

Diretório padrão utilizado pela API (`UPLOAD_DIR=../upload-dir`) para armazenar e servir arquivos enviados pelos endpoints `/api/files/v1`.

> Os arquivos enviados localmente são ignorados pelo `.gitignore` para manter o repositório leve; apenas `.gitkeep` e este `README.md` permanecem versionados.
